# Create T3 App

This is the application generated during workshop step 1, using Create T3 App `7.40.0`.
The parent folder is the toolbox; this `my-app/` folder is where you run app commands.

1. Read [this branch's checkpoint](../docs/CHECKPOINT.md) to find your next step.
2. Follow the [workshop guide](../docs/WORKSHOP.md) for installation, sign-in, and storage.
3. Use the [guide index](../docs/README.md) for recovery instructions and optional exercises.

On step 1, apply the reviewed package settings before installing. On steps 2-6, run
`npm ci` in this folder to install the versions in the app's lockfile.

Your private `.env`, installed dependencies, generated Prisma client, and SQLite database
are not included in Git. No branch supplies working OAuth credentials or signs you in.
No seed script is needed: you create your own first record through the page in step 5.
