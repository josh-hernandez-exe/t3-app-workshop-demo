# Cloud Workshop: Build a Small Web App

Start on **`main`**. This branch is a toolbox, not a finished application.
During the workshop you will generate a T3 app, connect Discord sign-in, and save a
record that survives restarting the app.

## Start Here

1. Before the session, follow [Setup](docs/SETUP.md). Stop when the generator prints `7.40.0`.
2. During the session, follow the [six-step Workshop](docs/WORKSHOP.md).
3. For help or extra practice, open the [guide index and branch map](docs/README.md).

No app should exist before the workshop. Setup installs the generator only; it does not
create `my-app/`, configure sign-in, create a database, or start a server.

## Using a Checkpoint?

The `workshop/step-*` branches are references for the numbered slides. Read
[this branch's checkpoint](docs/CHECKPOINT.md) before running anything. Credentials,
installed packages, and saved records are never included in a branch.

Keep working in your own copy of `main`. Use the [recovery instructions](docs/README.md#use-a-checkpoint-safely)
only when you need help catching up; do not switch branches over your work.
